# Praise Privacy

Praise is an offline-first lyrics app.

## Local Data

Praise stores songs, favorites, lists, custom lyrics, and saved song photos in
local app storage on the user's device.

## Camera And Photos

Camera and photo access are used only when the user chooses to scan a song or
keep a song photo. Saved photos remain in local app storage unless the user
shares or deletes them.

## OCR And On-Device AI

OCR runs on the device where supported. On supported Android devices, OCR text
may be passed to Android on-device AI APIs to help structure a song draft. The
user reviews the draft before saving.

## Network Use

Praise uses network access for:

- Refreshing the public song catalogue
- Opening YouTube practice videos
- Opening shared list links
- Submitting feedback, problem reports, or song requests

Feedback and song requests may become public GitHub issues. Users should avoid
including private information in those submissions.

## Community Catalogue

Catalogue songs are community-provided. Praise does not intend to use anyone's
work without permission. If your work appears in the catalogue without consent,
please report the song so it can be reviewed for removal.

## Accounts

Praise does not require a user account for the offline lyrics, favorites, lists,
custom songs, or local scan flow.
