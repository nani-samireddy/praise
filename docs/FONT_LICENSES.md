# Bundled Telugu Fonts

Praise bundles the following font files from the official Google Fonts
repository. They are packaged with the application so the reader and Settings
preview work completely offline.

| Settings name | Flutter family | Source | Local license |
| --- | --- | --- | --- |
| Noto Sans Telugu | `NotoSansTelugu` | [Google Fonts family](https://github.com/google/fonts/tree/main/ofl/notosanstelugu) | `assets/fonts/licenses/NotoSansTelugu-OFL.txt` |
| Noto Serif Telugu | `NotoSerifTelugu` | [Google Fonts family](https://github.com/google/fonts/tree/main/ofl/notoseriftelugu) | `assets/fonts/licenses/NotoSerifTelugu-OFL.txt` |
| Mandali | `Mandali` | [Google Fonts family](https://github.com/google/fonts/tree/main/ofl/mandali) | `assets/fonts/licenses/Mandali-OFL.txt` |
| Ramabhadra | `Ramabhadra` | [Google Fonts family](https://github.com/google/fonts/tree/main/ofl/ramabhadra) | `assets/fonts/licenses/Ramabhadra-OFL.txt` |

Each family is distributed under the SIL Open Font License included at the
listed path. Keep the corresponding license file with any redistributed font.
