# Praise Song Studio

A static, browser-based tool for formatting worship songs, adding musical metadata, maintaining original and transliterated lyrics, positioning chords, and exporting structured JSON.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

GitHub will display the public website URL after deployment completes.

## Development

No installation or build command is required. Open `index.html` directly or serve the folder with any static web server.

Song drafts are stored locally in the browser using `localStorage`. No lyrics or metadata are sent to an external server.
